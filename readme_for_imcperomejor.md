# IMC Pero Mejor

¡Bienvenido/a a **IMC Pero Mejor**! Este proyecto está diseñado para ofrecer una perspectiva más completa, moderna y amigable sobre el cálculo del Índice de Masa Corporal (IMC) y el seguimiento de la salud física.

---

## 🌟 Características Principales

* **Cálculo Preciso:** Obtén tu IMC de forma rápida y sencilla ingresando tu peso y altura.
* **Interpretación Avanzada:** Más allá de un simple número, el sistema ayuda a comprender el contexto detrás de las métricas corporales.
* **Interfaz Intuitiva:** Un diseño limpio, accesible y fácil de usar en cualquier dispositivo.
* **Enfoque Integral:** Promueve una visión de la salud que va más allá de los estándares tradicionales del IMC.

## 🚀 Tecnologías Utilizadas

Este proyecto utiliza tecnologías web modernas para garantizar un rendimiento óptimo:
* **HTML5 / CSS3 / JavaScript** (o el stack correspondiente según la implementación).

## 📦 Instalación y Uso

Si deseas clonar y ejecutar este proyecto de manera local en tu computadora, sigue estos sencillos pasos:

1. Clona el repositorio:
   ```bash
   git clone https://github.com/VictoriaBalanda/imcperomejor.git
   ```

2. Entra al directorio del proyecto:
   ```bash
   cd imcperomejor
   ```

3. Abre el archivo principal (por ejemplo, `index.html`) en tu navegador web preferido o ejecútalo con tu entorno de desarrollo local.
